# 已知问题：高精度模式

**状态：25 MHz + CRC32 版已由用户确认不再出现 PHOTO ERROR；白条仍在，单次显示固定、轮播重新加载后迁移。新候选改为显存四字分组写入和组间暂停并增加分阶段开场进度，白条仍待实板确认。**

高精度 RGB888 模式切换图片时，可能出现横向白条、短暂闪黑，自动轮播也可能出现异常。当前版本保留该模式供后续排查，不作为已完成验收的功能；日常使用建议选择普通精度 RGB565。

用户确认白条会在切换后持续保留。本分支发现 A/B 的 SDRAM 读写状态机均未阻止刷新期间发命令，可能造成永久缓存缺字。修正后，读写命令、FIFO 弹出、地址和计数在刷新期间一起暂停。真实 FIFO 的对照仿真复现旧代码缓存损坏，修正后 RGB565/RGB888 目标缓存和读出全部一致。详细证据、局限和操作见 [RGB888_SWITCH_FIX.md](RGB888_SWITCH_FIX.md)。A 板显示读侧仍保留 768 字预留。

本次 BOOT_RECOVERY 版本的“无法启动、一直卡在加载画面”问题，已由用户上板确认解决。此确认不代表上述高精度切图问题已解决。

此前 RGB888_LINK_FIX 尝试曾出现启动回归；本发布已撤回其中新增的接收握手和显存读完成计数，恢复此前可启动的图片收发路径。

当前配套版本和诊断码说明见 [WHITEBAR_LINK25_CRC_README](delivery/WHITEBAR_LINK25_CRC_README.md)。两板必须同时更新。
