# V3.1 高精度切换闪黑修复候选

本版基于 dual_transparent_fx；修复 A 板显示读取与后台预取写入争用 SDRAM 的路径。手动切图、随机转场和自动轮播共用此路径。

- 显示 FIFO 从 512 个 32 位字扩大到 1024 字，保持原双时钟 Gray 指针、同步和输出延迟。
- 高精度显示有活动读任务、FIFO 少于 512 字时，预取停止申请新的写突发；已开始的 128 字写突发仍完整结束。
- 写入等待时释放申请，避免写入和显示读取互相等待。首次加载和读帧完成后允许写入。
- B 板、开机音画同步、透明频谱/波形和奖杯播放保持原版。所有六种高精度转场继续支持。
- 渐暗本身仍经过黑色中点，这是该效果的定义；本次针对的是额外的整帧欠载闪黑。

新增 tests/tb_rgb888_bandwidth.v 使用实际 FIFO RTL，75 MHz 像素时钟、50 MHz 显存用户时钟和 12 周期读响应模型，同时读取完整 720p RGB888 帧并持续写入预取数据。修复前源码保存在 tests/reference/rgb888_switch_before，可通过 tools/test_rgb888_bandwidth.py 重现对比。

此模型验证用户接口调度和 FIFO，不替代板上的实际 SDRAM 控制器、刷新和布线时序验收。最终以板上随机转场和自动轮播连续测试为准。

## 实测仿真结果

相同完整帧压力测试：旧版读空 184149 次、显示读出 507051 字；修复版读空 0 次、完整读出 691200 字。修复版同时接收 63111 字预取数据，读写命令无重叠。该测试的存储器响应为建模结果，不是板上测量。
