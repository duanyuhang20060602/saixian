# MOUSE.HMI

本目录的 `MOUSE.HMI` 为用户保存的陶晶驰可编辑工程，原样复制自工作区根目录的同名文件，未由本端修改、编译或重新导出。

- 屏型号：本次测试使用TJC8048T070，800×480。
- FPGA串口：115200、8N1，触点协议 `A6 XL XH YL YH DOWN SUM FF FF FF`。
- HMI文件大小：10,884,012字节。
- SHA256：`5936bb06072698797213d85e012529c641b158a1706cd4bc351204c2c7acec42`。

用陶晶驰编辑器打开工程并编译为TFT后下载到屏。当前发布不含TFT；已运行已验证界面的屏无需重复下载。单板固件默认启用触控，同时支持现有页面的31启用/关闭命令。

接线与上板步骤见 [物理接线说明](../WIRING.md)，FPGA行为及构建方法见 [单板测试说明](../README.md)。
