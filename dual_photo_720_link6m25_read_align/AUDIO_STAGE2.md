# AUDIO2：B 音频处理，A 频谱与比赛界面

## 已上传的实板正常基线

2026-10-14 已将用户确认正常的 BGSCAN 版本上传到 GitHub，提交 `2b2a97b`，分支 `codex/dual-photo-720p-high-speed-switch`。该提交保存源码、匹配 A/B bit、打包文件和正确的 J2 接线。AUDIO2 是在此版本上新增的单板音频功能移植，实板结果需要重新确认。

## A/B 分工

- B：TF 扫描及读音频、原始 PCM 缓冲、提示音合成、提示音与音乐混合、音量缩放，最后发出处理后的 16 位立体声 PCM。
- A：比赛状态机、按键及串口屏控制、48 kHz 播放时序、HDMI 音频输出、音量/比赛界面、频谱显示。
- 图片继续由 B 处理、A 四图缓存显示；找到素材后先播放，目录扫描在空闲时继续。比赛期间固定当前图片并停止手动/自动切图。

单板目前没有独立的降噪、失真恢复或其他“音频修复”算法；本次移植的是已有音量处理、恢复默认、提示音混合及音频显示，不添加未存在于单板的修复算法。

## 板上按键

| 场景 | KEY1 | KEY2 | KEY3 | KEY4 |
|---|---|---|---|---|
| 普通图片/音乐播放 | 下一张图片 | 下一首音乐 | 进入设置 | 短按释放后下一张；长按约 1 秒开始比赛 |
| 设置 | 下一项 | 减少 | 退出 | 增加 |
| 比赛准备/运行/暂停 | 准备时再次开始，可提前进入倒计时 | 运行/暂停之间切换 | 结束/取消比赛 | 长按发出开始请求 |

### 统一设置界面

KEY3 进入／退出同一个 HDMI 设置面板，KEY1 依次选中下面 11 项，KEY2 减少或关闭，KEY4 短按增加或开启。最后一项之后回到音量。

| 项目 | 范围／选择 |
|---|---|
| 音量 | 0~8，默认 5；0 静音，8 原幅度 |
| 亮度、对比度 | 各 0~8 |
| 细节 | 0~3 |
| 饱和度 | 0~8 |
| 反色、复古 | 关闭／开启 |
| 增强 | 0~2 |
| 切换方式 | 随机、左右滑动、中心展开、百叶窗、对角、溶解、渐暗 |
| 自动轮播 | 关闭／开启；默认关闭，每次转场结束后约 5 秒请求下一张 |
| 音频显示 | KEY2 选择频谱，KEY4 选择波形；默认频谱 |

显示模式只改变 A 板可视化，不重新读取歌曲、不清空音频 FIFO。所有菜单项都使用同一个画面流水，页面显隐与选项在帧边界锁存。


## 单板比赛流程

准备 → 3/2/1 倒计时 → 开始 → 运行累计计时 → 暂停/继续 → 结束 → 返回普通播放。准备约 2 秒后自动进入倒计时，准备时再次开始可提前进入倒计时。比赛运行显示分钟和秒，暂停停止累计。结束界面约 3 秒后返回，结束提示音播放后约 1 秒恢复背景音乐。

准备、倒计时、比赛运行及暂停阶段暂时关闭背景音乐，提示音仍由 B 合成并传输；关闭背景音乐时 B 保留原始音乐 FIFO 和读卡位置。提示音按每个发送的 PCM 帧推进，音调和时长不受 TF/SPI 突发读取速度影响；静音段也正常计数。

## 串口屏命令

115200 8N1，格式仍为 `55 CMD VALUE 00 FF FF FF`。

| 操作 | 示例 |
|---|---|
| 开始比赛 | `printh 55 01 00 00 ff ff ff` |
| 暂停/继续切换 | `printh 55 02 00 00 ff ff ff` |
| 结束/取消 | `printh 55 03 00 00 ff ff ff` |
| 明确暂停 | `printh 55 06 00 00 ff ff ff` |
| 明确继续 | `printh 55 07 00 00 ff ff ff` |
| 下一首歌曲 | `printh 55 08 00 00 ff ff ff`，普通播放时有效 |
| 音量 0~100% | `printh 55 14 32 00 ff ff ff`，示例为 50%，量化到 0~8 档 |
| 频谱显示 | `printh 55 1a 00 00 ff ff ff` |
| 波形显示 | `printh 55 1a 01 00 ff ff ff` |
| 恢复单板默认设置 | `printh 55 1f 00 00 ff ff ff`，包括音量及现有图像设置 |
| 选择比赛项目 | `printh 55 24 00 00 ff ff ff`，VALUE=00/01/02，普通播放时选择 |

A 使用现有状态发送模块回传歌曲数、音量、比赛状态和 `MM:SS`，沿用单板 HMI 的控件命名与页面通知协议。此任务未修改 HMI 工程文件，已有开始、暂停、继续、结束按钮可继续发送原命令。

## 波形／频谱显示

沿用单板的 32 柱显示方式：峰值包络和零交叉周期估计主频，附近柱与弱谐波做可视化。它不是 FFT 或准确的多频能量测量。A 对实际播放的音量处理后 PCM 进行分析，帧边界锁存显示参数，避免同一帧的柱高度变化。

频谱沿用单板的柱状布局。波形采集实际播放 PCM 的高 8 位，每 16 个音频样本保留一点，64 点覆盖约 21.3 ms；双缓冲在帧边界交换，避免绘制时数据被更新。普通播放显示在图片下方区域，比赛界面显示在计时区域下方。它用于观察波形，不是完整带宽的测量仪器。

HDMI 图像保持 1280×720；单板 640×480 逻辑界面映射到完整 720p，新增五拍界面流水，总视频 RGB/DE/SOF/EOL 延迟统一为 26 拍。

## 接线及协议

接线不增加：J2-24 MOSI、J2-27 SCLK、J2-28 CS、J2-31 MISO，共地 J2-12 或 30。J2-29 是电源。音频 SPI 仍为 3.75 MHz；新增音频通道不使用 CRC16。

A 的 32 位请求新增背景音乐使能、音量和提示音字段；B 状态和 128 帧 PCM 返回格式沿用上一版。歌曲/控制代号用于确认新设置，提示音仅在新代号到达时触发一次。两板必须同时使用 AUDIO2 bit，不能混用 BGSCAN bit。

切歌、音量变化和提示音事件会清空 A 的旧播放队列并重新缓冲，以避免旧音量或音乐盖住新提示音。音量及比赛控制不会让 B 重新从歌曲开头读卡，但可能丢弃约 90 ms 以内已排队的音乐并产生短暂静音；当前不承诺无缝切歌或完全无损的暂停位置。

## 构建与验收

本阶段未运行功能仿真。编译及布局布线证据在 VALIDATION.md；单板源码移植和时序通过不等于实板验收。需确认音乐及切图仍正常、频谱位置、音量/静音、恢复默认、长按 KEY4 比赛流程、倒计时提示音、暂停/继续/结束及 HMI 计时回传。BGSCAN 原版的实板确认仅适用于提交 `2b2a97b`。

### MENUFIX

修复设置项从 0 切到 1 后黑屏：单板 OSD 在 DE 为低时输出黑色，并不透传输入 RGB。图像设置页现在通过等长五拍 RGB 旁路输出，继续保持全链路 26 拍。仅 A 逻辑改变，B 可沿用 AUDIO2。新版需上板确认菜单切换，未运行功能仿真。

### UNIFIED MENU

将音量和图像设置合并为一个 11 项面板，切换方式显示中文名称，增加音频显示选择。A 增加波形快照；B 处理逻辑未改变，可沿用此前 AUDIO2／MENUFIX bit。本包仍附带匹配 B bit，便于完整烧录。未运行功能仿真，实板确认待完成。
