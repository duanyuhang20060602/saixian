# TF 卡背景音乐文件

`BGM.PCM` 是从 `F:\bgm.wav` 的 `data` 区直接提取的未压缩 PCM 数据。
`BGM.AUD` 是实际上卡使用的文件：前 512 字节为 FPGA 可识别的对齐头，后面是完全相同的 PCM 数据。

- 采样率：48000 Hz
- 采样格式：signed 16-bit little-endian (`s16le`)
- 声道：2（立体声）
- 帧布局：`L0低字节, L0高字节, R0低字节, R0高字节, L1...`
- 每帧：4 字节
- 数据率：192000 字节/秒
- 循环方式：读到文件末尾后回到数据起点

## 上卡要求

1. 新版最多识别 5 首 `.AUD`，按物理扇区出现顺序编号 1～5；也兼容只有一首的旧卡。不要把 `.PCM`、WAV 或同一首的重复 `.AUD` 放进专用卡。
2. 在轮播状态按住 K4 约 1 秒，即切换到下一首；松开后才能再次长按。短按 K4 仍用于设置页加值。扫描没找到两首以上时，长按不会切歌。
3. FPGA 不依赖文件名，而是识别每首 `.AUD` 首扇区中的 `SXAUD001` 标记。可用 `doc/convert/convert_audio_to_aud.py` 制作文件；该脚本依赖 Python 3.12 或更早版本的 `audioop`。
4. 裸扇区扫描要求文件连续，建议先备份专用卡，再在干净的 FAT32 卡上一次性复制五张轮播 BMP、一张带标记的百米 BMP 和最多五首 AUD。不要直接运行旧版 `sync_to_sd.py`：它只处理五图且会清空卡。此次没有操作 TF 卡。

头部字段均为小端：偏移 0 为 8 字节标记，偏移 8 为 PCM 字节数，偏移 12 为采样率，偏移 16 为位深，偏移 18 为声道数，偏移 20 为数据起始偏移（固定 512）。

扫描器在全部目标文件找到或连续约 20 秒没有新文件后结束，另有 240 秒安全上限。所以上电等待时间与卡内数据位置有关，不应把延迟直接判定为卡故障。
