# 陶晶驰屏端事件代码 v1

适用屏幕：`TJC8048X570_011C`，800x480 横屏。

串口参数：115200 baud、8N1。屏到 FPGA 的固定帧为：

```text
55 CMD VALUE 00 FF FF FF
```

- `CMD`：命令编号。
- `VALUE`：按钮命令填 `00`；滑块命令为控件当前值。
- 每个控件的“发送键值”必须取消勾选，否则屏幕还会额外发送 `65 ... FF FF FF`。
- 滑块只在“弹起事件”发送，滑动事件仅更新数字显示。

## 页面和控件

主页面命名为 `main`，确认页面命名为 `confirm`。

| 控件 | 类型 | 范围/初值 |
|---|---|---|
| `b_start` | 按钮 | 开始比赛 |
| `b_pause` | 按钮 | 暂停/继续 |
| `b_finish` | 按钮 | 打开结束确认页 |
| `b_prev` | 按钮 | 上一张 |
| `b_next` | 按钮 | 下一张 |
| `h_sharp` / `n_sharp` | 滑块/数字 | 0..3，初值 1 |
| `h_bright` / `n_bright` | 滑块/数字 | 0..100，初值 50 |
| `h_contrast` / `n_contrast` | 滑块/数字 | 0..100，初值 50 |
| `h_saturation` / `n_saturation` | 滑块/数字 | 0..100，初值 50 |
| `h_volume` / `n_volume` | 滑块/数字 | 0..100，初值 62 |
| `b_image_reset` | 按钮 | 恢复默认值 |
| `b_confirm_finish` | 按钮 | 确认结束比赛 |
| `b_cancel` | 按钮 | 取消结束比赛 |

## 按钮弹起事件

`b_start`：

```text
printh 55 01 00 00 ff ff ff
```

`b_pause`：

```text
printh 55 02 00 00 ff ff ff
```

`b_finish`：

```text
page confirm
```

`b_prev`：

```text
printh 55 04 00 00 ff ff ff
```

`b_next`：

```text
printh 55 05 00 00 ff ff ff
```

`b_confirm_finish`：

```text
printh 55 03 00 00 ff ff ff
page main
```

`b_cancel`：

```text
page main
```

## 滑块事件

`h_sharp` 的滑动事件：

```text
n_sharp.val=h_sharp.val
```

`h_sharp` 的弹起事件：

```text
n_sharp.val=h_sharp.val
printh 55 10
prints h_sharp.val,1
```

## 恢复默认按钮

`b_image_reset` 的弹起事件：

```text
h_sharp.val=1
n_sharp.val=1
h_bright.val=50
n_bright.val=50
h_contrast.val=50
n_contrast.val=50
h_saturation.val=50
n_saturation.val=50
h_volume.val=62
n_volume.val=62
printh 55 1f 00 00 ff ff ff
```

## 命令编号

| CMD | 功能 |
|---|---|
| `01` | 开始 |
| `02` | 暂停/继续 |
| `03` | 结束 |
| `04` | 上一张 |
| `05` | 下一张 |
| `10` | 锐度 0..3 |
| `11` | 亮度 0..100 |
| `12` | 对比度 0..100 |
| `13` | 饱和度 0..100 |
| `14` | 音量 0..100 |
| `1F` | 全部恢复默认 |
