# 陶晶驰串口屏工程制作与烧录

## 1. 新建工程

1. 打开陶晶驰 `USART HMI` 上位机。
2. 新建工程，设备必须选 `TJC8048X570_011C`。型号不一致时下载会提示 `model does not match`。
3. 分辨率选 800x480、横屏，字符编码建议选 UTF-8。
4. 建立 `main` 和 `confirm` 两个页面。
5. 将 `saixian_hmi_ui_concept_v2.png` 导入图片资源，可作为主页面背景或布局参考。
6. 按《陶晶驰屏端事件代码_v1.md》的名称建立按钮、滑块和数字控件，再把对应代码粘贴到控件事件中。
7. 所有自定义协议控件都取消勾选“发送键值”。

## 2. 编译前检查

1. `h_sharp` 范围设为 0..3，初值 1。
2. 亮度、对比度、饱和度范围设为 0..100，初值 50。
3. 音量范围设为 0..100，初值 62。
4. 工程波特率设为 115200、8N1。
5. 先点“调试”，在模拟器里点击按钮；串口数据显示应符合 `55 CMD VALUE 00 FF FF FF`。
6. 点击“编译”，必须为 0 个错误；编译后会生成可下载的 TFT 数据。

## 3. 用 USB 转 TTL 下载到屏幕

下载时不要让 FPGA 和 USB 转 TTL 同时连接屏幕串口，避免两个发送端并联冲突。

接线：

```text
USB-TTL TX  -> 屏幕 RX
USB-TTL RX  -> 屏幕 TX
USB-TTL GND -> 屏幕 GND
外部稳压 5V 正极 -> 屏幕 5V
外部稳压 5V 负极 -> 屏幕 GND
```

7 寸 X5 屏不建议依靠小型 USB 转 TTL 模块供电。使用独立稳压 5V 电源，建议预留 2A 能力；USB 转 TTL 与外部电源必须共地。

烧录步骤：

1. 在 Windows 设备管理器确认 USB 转 TTL 对应的 COM 口。
2. 在 USART HMI 中打开已编译工程，点击工具栏“下载”。
3. 选择对应 COM 口。首次建议使用 115200 下载，稳定后再提高下载波特率。
4. 给屏幕重新上电，等待软件联机并完成下载。
5. 出现下载完成后，关闭下载窗口并重新上电检查界面。

如果联机失败，依次检查 TX/RX 是否交叉、GND 是否共地、COM 口是否被其他串口助手占用、屏幕是否因供电不足反复重启。

## 4. 烧录后连接 FPGA

先拔掉 USB 转 TTL，再连接 FPGA：

```text
屏幕 TX -> 5V转3.3V电平转换 -> J1-1 GPIOA_0 / FPGA D14 (hmi_uart_rx)
屏幕 RX <- J1-2 GPIOA_1 / FPGA G11 (hmi_uart_tx，当前保持空闲高电平)
屏幕 GND --------------------> J1-12 GND，且与外部5V电源负极共地
屏幕 5V ---------------------> 独立稳压5V电源正极
```

X5 屏 TX 为 5V 串口电平，禁止直接接 FPGA。FPGA 的扩展 GPIO 是 3.3V；至少要在“屏幕 TX -> FPGA RX”方向使用可靠的电平转换。简单分压也能用于低速验证，但正式使用建议采用 74LVC1T45、SN74LVC2T45 等电平转换器。

本工程没有占用板载 CH340 的 F12/D12，而是使用空闲 J1 扩展口，便于屏幕与电脑下载口互不干扰。
