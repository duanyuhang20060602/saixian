# 赛显串口屏 UI 设计 v1

目标设备：TJC8048X570_011C，800x480，横屏。

## 主界面布局

- 顶栏：设备在线、HDMI 状态、TF 卡状态。
- 左侧主卡片：赛事状态、MM:SS 计时和赛事进度。
- 右侧操作区：开始、暂停/继续、结束、上一张、下一张。
- 底部调节区：锐度、亮度、对比度、饱和度和恢复默认。
- “结束比赛”使用红色危险色，并在执行前弹出确认页，防止误触。

## 陶晶驰控件命名

| 功能 | 控件类型 | 建议名称 | 范围/状态 |
|---|---|---|---|
| 赛事状态 | 文本 | `t_state` | 轮播/准备/比赛中/暂停/结束 |
| 赛事计时 | 文本 | `t_timer` | `MM:SS` |
| 赛事进度 | 进度条 | `j_progress` | 0-100 |
| 开始比赛 | 按钮 | `b_start` | 事件命令 0x01 |
| 暂停/继续 | 按钮 | `b_pause` | 事件命令 0x02 |
| 结束比赛 | 按钮 | `b_finish` | 打开确认页 |
| 上一张 | 按钮 | `b_prev` | 事件命令 0x04 |
| 下一张 | 按钮 | `b_next` | 事件命令 0x05 |
| 锐度 | 滑块+数字 | `h_sharp` / `n_sharp` | -4 至 +4，默认 0 |
| 亮度 | 滑块+数字 | `h_bright` / `n_bright` | 0-100，默认 50 |
| 对比度 | 滑块+数字 | `h_contrast` / `n_contrast` | 0-100，默认 50 |
| 饱和度 | 滑块+数字 | `h_saturation` / `n_saturation` | 0-100，默认 50 |
| 恢复默认 | 按钮 | `b_image_reset` | 0/50/50/50 |

滑块只在松手事件发送参数，拖动过程中仅更新本地数字，避免连续串口数据淹没 FPGA 接收器。

## FPGA 实现边界

当前工程尚未实现锐度、亮度、对比度和饱和度调节。UI 控件可以先完成，但要真正生效，后续需要：

1. 增加 UART 接收、帧校验和寄存器映射。
2. 在视频通路中增加亮度、对比度和饱和度运算。
3. 锐度使用 3x3 卷积或简化反遮罩算法，需要至少两行像素缓存。
4. 图像调节应放在画面缩放之后、OSD 叠加之前，避免把状态文字一起锐化或改色。
5. 所有运算结果必须饱和限制到 0-255，不能依赖自然溢出。

## 串口约束

- 波特率：115200，8N1。
- 每条陶晶驰 ASCII 指令以 `FF FF FF` 结束。
- 屏幕到 FPGA 的控制消息使用固定帧头和校验；参数滑块采用有符号或无符号单字节值。
- X5 屏串口输出可能为 5V，连接 FPGA 前必须进行 5V 到 3.3V 电平转换。
