# SXDLT001

所有整数均小端。文件、各帧编码起点和填充按 512 字节扇区对齐。每个 SDRAM 32 位字保存两个 RGB565 像素：低 16 位是扫描顺序第一个像素，高 16 位是第二个。

文件头 512 字节：

|偏移|类型|值或含义|
|---|---|---|
|0|8 bytes|SXDLT001|
|8|u16|版本 1|
|10|u16|头长度 512|
|12、14|u16|宽、高，均为 480|
|16|u32|原 GIF 帧数 27|
|20|u32|文件总字节数|
|24|u32|帧字数 115200|
|28|u32|索引起始扇区 1|
|32|u32|索引项长度 32|
|36|u32|文件偏移 512 至文件末尾的 CRC32，包括填充|
|40|u32|描述符数量，原 GIF 帧数 + 1|

索引每项为 8 个 u32：编码起始文件字偏移、编码字数、显示时长（50 MHz 时钟拍数）、解码 RGB565 CRC32、编码流 CRC32、原帧号、保留 0、保留 0。硬件装载验证整个包 CRC；索引内两个单帧 CRC 供转换器/软件校验。

描述符 0 是启动完整首帧；描述符 1..26 是上一原帧至当前原帧的增量；描述符 27 是原帧 26 至原帧 0 的增量。初始化后循环 1..27。这样回首帧无需再次写完整首帧。

每条命令是 u32，高两位为类型、低 30 位为正数计数。计数单位是像素对（32 位字）。

|高两位|含义|后续数据|
|---|---|---|
|00|跳过不变字|无|
|01|复制 literal 字|计数个 u32|
|10|重复同一个字|一个 u32|
|11|非法/保留|无|

从帧内字地址 0 开始执行，末尾必须恰好到达 115200。解码器拒绝零计数、越界、保留类型和缺失 literal/fill 数据。非显示缓存写入后切换显示，再向另一缓存重放同样的增量。
