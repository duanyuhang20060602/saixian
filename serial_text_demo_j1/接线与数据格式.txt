J1打字demo：FAT16/FAT32普通复制版（2026-10-30）

本说明取代旧版固定扇区/镜像写卡步骤。当前releases/TEXT_DEMO_J1.bit已经加入只读文件系统。

一、只需两个文件
1. FPGA：重新烧录releases/TEXT_DEMO_J1.bit。
2. TF卡：将本工程TF卡文件/FONTS.BIN普通复制到卡的根目录。
卡根目录应直接看到FONTS.BIN，不要把“TF卡文件”整个文件夹当根目录；不要只复制.img文件。
不需要镜像工具，不需要原始扇区写入，不要求先放字库，也不要求连续存放。碎片文件沿FAT簇链读取。
旧demo镜像卡也兼容：它已有合法FAT16文件系统，可直接替换根目录FONTS.BIN，不用再写镜像。

二、卡的格式
支持FAT16或FAT32、512字节逻辑扇区；可识别MBR主分区或无分区表直接放文件系统的卡。
如有多个分区，使用第一个受支持的FAT主分区；仅在该分区根目录查找FONTS.BIN。
不支持exFAT、NTFS、FAT12、GPT、扩展/逻辑分区及子目录查找。
如果卡本来就是FAT16/FAT32，无需格式化，直接复制文件，卡上的其他文件可保留。
若卡是exFAT/NTFS，先备份后使用FAT32卡；格式化会清空数据。本工程程序不自动格式化、不写实体TF卡。
文件名固定为FONTS.BIN（标准8.3短文件名），勿命名为FONTS.BIN.bin或放进子文件夹。

三、接线与上电
只使用一块HX4S20/EG4S20BG256板。
串口屏TXD → J1-1（FPGA D14）；串口屏RXD ← J1-2（G11）；共地 → J1-12。
UART：3.3V TTL，115200，8N1。屏按铭牌独立供电，并共地。J2完全不接。
TF插在烧录demo并连接HDMI1的同一块FPGA板，不是串口屏或另一块板的卡槽。
安全弹出TF，断电插卡，再给板子上电。复制或替换字库后重启以重新挂载。

四、画面提示
SD INIT 0～3：底层卡初始化，尚未读文件系统。停在SD INIT 2与复制方式无关。
READ FONT：挂载FAT、查找FONTS.BIN并读取字库头。
FONT OK TYPE NOW：字库头已读取并匹配，可以发送文字。该提示不代表所有字形数据均已完整校验。
FAT ERROR 1：启动扇区签名不正确。
FAT ERROR 2：不支持的分区/文件系统/扇区大小，或FAT参数无效。
FAT ERROR 3：根目录找不到FONTS.BIN，目录簇链结束，或根目录超过扫描上限（4096扇区）。
FAT ERROR 4：文件起始簇、后续簇链或文件长度无效。
FAT ERROR 5：扇区/文件范围错误。
FAT ERROR 6：文件系统读取缺少进展而超时。
FONT ERROR：文件找到后字库头不匹配，或上层读字超时。
底层卡没初始化完成时，FAT读取方式不能直接解决接触、接错卡槽或卡兼容性问题。

五、串口测试
显示FONT OK后，串口屏按钮或定时器事件：
printh 40 30 3A 54 45 53 54 0D 0A
即发送@0:TEST后跟CR LF。电脑助手用HEX模式发送相同9字节。
RX增长只表示收到字节；OK增长表示文字请求被接受；ERR增长表示错误应答。
新文字在下一次消隐立即显示，轮播跳过空槽。只有一段非空就持续显示它；多段各约3秒轮播。
每10秒心跳、接收计数、最后字节、指定字符闪烁等原功能保留。
原始ASCII格式：@槽号:GB2312文字\r\n，槽号0～3，每段16字以内，^标记下一个字闪烁。
清空槽0：40 30 3A 0D 0A；内容保存在运行RAM中，断电后重新输入。
串口屏的拼音选字由屏端HMI完成，本包不包含新编译的屏端TFT。可继续使用之前配置的发送按钮/定时器。

六、与示例工程的关系
底层模块来自585ea40基线：sd_card_top、sd_card_sec_read_write、sd_card_cmd和spi_master。
命令流程沿用官方18_sd_card_audio示例的CMD0、CMD8、CMD55/ACMD41、CMD16与CMD17读扇区。
这些是已在5.0中演进的模块，不声称与官方压缩包中的原始源码逐字节相同；当前demo读卡时钟域为75MHz。
新增demo_fat_font只处理分区、FAT参数、目录和簇链，向底层发扇区请求；没有替换底层SPI状态机。
原demo内部2209仍作为上层请求的虚拟基址存在，但不再是TF物理扇区。实际位置由FAT计算。

七、字库格式与重生成
FONTS.BIN第0扇区头为ASCII SXFONT01；后续每字16×16单色、32字节，逐行大端，bit15在左。
ASCII字形索引0～127；GB2312字形索引=128+(高字节-A1)*94+(低字节-A1)。
共有8964个索引槽；未分配的GB2312位置使用问号，并非8964个有效汉字。
文件偏移=512+字形索引×32。镜像物理基址已取消，普通复制即可。
重新生成：python tools/make_font_card.py --out TF卡文件
默认只生成FONTS.BIN，不生成镜像。--legacy-image仅供旧版测试。

八、验证与限制
已有FAT16/FAT32、主分区/无分区、碎片簇链、活动FAT、根目录跨簇、65535以上簇号与缺失/坏簇等仿真。
真实UART到碎片FAT32、行为/厂商RAM和8192个像素对照均验证；最终资源与时序见releases/build.json。
这些是软件与厂商工具结果，实际TF卡和串口屏仍需上板复验。
