# KEY2 TF 动图预加载与静图仲裁修复版

基于 20261008 的 d23efef，接入 20261010 的 88a9b975 动图播放器与素材。当前交付目录为 releases/key2_tf_static_fix_20261011/；上一预加载版 releases/key2_tf_preload_20261010/ 和未预加载版 releases/key2_tf_20261010/ 均保留。

2026-10-11 修复：动图缓存会在退出后继续保留，但其每帧 FIFO 清理和命令 FIFO 清理原先会直接改变 SDRAM 归属，截断静图正在发出的读请求或延迟返回的数据。现在本地 FIFO 清理不再取得 SDRAM 控制权；真正的动图读写仍等待静图释放总线、实际 SDRAM 事务结束且刷新完成。针对结算静图和后续轮播抖动的反馈修改；用户已确认本版实板通过，并批准上传 GitHub。验收来源和位流哈希记录在交付目录的 board_confirmation.json。

## 操作与切换

1. 轮播时 KEY2 短按并松开选择蓝方胜利；长按约 1 秒选择红方胜利。胜利开始时后台预加载动图。
2. 胜利停稳后按 KEY2，进入 100 米排名及领奖台；后台继续准备首帧。
3. 领奖台停稳后按 KEY2 播放动图。准备好时在场消隐期间切换；仍在读取、校验或准备首帧时继续显示领奖台，准备好后自动切换，不转白圈、不插入加载黑屏。
4. 动图播放或等待期间再按 KEY2，返回 SDRAM 保留的轮播图片；正常退出无需重新初始化 TF 卡、扫描或重建当前图片，不转蓝圈。HMI 停止结算命令也可退出。

切换在共同的视频场消隐期间进行，避免活动画面中途换源。正常重入复用 SDRAM 动图文件缓存，首帧在下一次结算期间重新准备，无需再读文件。首次加载时间取决于卡速及文件位置；结算结束前未完成时，领奖台保持到首帧完成。上电加载和真实错误提示保留。

为在 8 MiB SDRAM 内同时保留图片和动图，轮播缓存当前图片和一个方向邻图，比赛背景单独保留。已缓存邻图可直接切换，另一方向未缓存的图片仍需读取。动图独立地址区最大容纳 **1,937,408 字节**，附带 TROPHY.DLT 为 **1,890,304 字节**。

## 设置与音量

“音频修复”第九项保留：KEY1 切换项目，KEY4 开启，KEY2 关闭，KEY3 退出；默认关闭。上午 V4 的 63 抽头 FIR、爆音及直流处理、开关渐变、切歌清理保留，与参考实现 10000 组双声道输出逐样本一致。

本次仅修改共用 SDRAM 的总线选择：本地 FIFO 清理期间保持图片通路。采用旧版通过时序的布局进行原生增量布线，冻结基准的哈希和 116 个用户源文件均核对；完整实现网表只改变一处查找表和两个空闲输入连接，布线后再次核对逻辑一致。

音量仍为 0–8，0 静音；增益依次为 0、0.25、0.5、0.625、0.75、0.875、1、1.125、1.25，超过满幅限幅。默认 5 档为 0.875 倍。设置、比赛中的 KEY2 原操作保留。动图阶段不播放背景音乐，退出后恢复轮播及音乐。

## TF 卡准备

将 examples/TF卡新增动图/TROPHY.DLT 放入 TF 卡，与原 BMP、AUD 共存。FPGA 读取转换后的 DLT，直接复制 GIF 不会播放。480×480 动图居中显示于 1280×720 画面，周围黑边。

仍采用连续扇区读取，文件须连续存储，起始位置在卡的前 512 MiB。可在备份后使用新格式化的 FAT32 卡，先复制 DLT 再复制 BMP/AUD。多个 DLT 会优先使用扫描中首先发现的有效文件。本版记录正常扫描发现的 DLT 扇区；没有位置记录时，动图扫描跳过已验证的 BMP/AUD 文件范围，减少无效读取。

文件 CRC、上传及 SDRAM 回读 CRC、逐帧预校验及解码校验保留。损坏文件不会发布半帧，可以按 KEY2 取消，下次结算时重试。超出容量报 E7；LED4 在动图阶段表示加载、校验、解码或欠载错误。真正读卡复位会清除缓存及位置记录并重新初始化，正常进出不会。

```powershell
python tests/run_key2_tf.py
python tests/run_tf_preload.py
python tests/run_preload_crc.py
python tests/run_static_bus_baseline.py # 上版抢占问题的预期失败对照

```

42 项检查包括 41 项仿真和实现网表核对：真实 27 帧逐帧 HDL 解码和循环衔接、预加载期间并行图片读取、1382400 个准确 RGB565 像素、缓存重入零读卡、保留图片地址区、刷新及掩码写入、实际损坏 CRC 的取消重试、实际读卡复位后的缓存失效和重新加载，场消隐切换，以及 262144 组 FIFO 指针对的满标志等价验证。新增静图总线归属测试采用正式图片读取器、正式动图仲裁器、48 周期延迟返回、刷新停顿和不同周期的帧/命令清理事件；上版能复现读请求被抢占，本版约 10 万次读取通过。新增完整实现网表核对和 16 组查找表真值检查，确认增量修复仅改变预期总线选择。完整真实素材的实时总线长测仿真未完成，仿真采用 SD/SDRAM 模型；2026-10-11 用户反馈本版实板通过，此反馈与仿真覆盖记录分别保存。
