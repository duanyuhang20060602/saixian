## 下载与对比

匹配源码、位流、测试和报告：`releases/photo/HDMI1.4b_Transmitter_v2.0.zip`。

BitWriter 中删除原文件行，再 Add 上述 photo 目录中的位流，器件应识别为 EG4S20BG256，使用 PROGRAM_SRAM 下载。此次无需更换 TF 卡素材或烧录串口屏。

本候选默认图像增强为 1，锐度为 1。操作含义如下：

| 设置 | 行为 |
| --- | --- |
| 图像增强 0 | 原图旁路，空间滤波与自适应提亮均关闭 |
| 图像增强 1、锐度 1 | 照片平滑与现有自适应提亮 |
| 图像增强 2、锐度 1 | 左半原图、右半照片处理，可在同一帧直接对比 |
| 图像增强开启、锐度 0 | 关闭空间修正，保留原有自适应提亮 |
| 图像增强开启、锐度 2/3 | 保留原有中/强锐化策略 |

“锐度 1”在本候选中的含义改为照片平滑档。HMI 串口协议、控件和数值范围保持不变。为了公平对比，亮度、对比度和饱和度保持中间档，并单独比较模式 0 与模式 1，避免把提亮造成的视觉差异误判为纹理修复。

上一资源优化版本仍保留在 `releases/HDMI1.4b_Transmitter_v2.0.bit` 及其 ZIP，原成功默认位流仍保留在 `src/td_project`。不同目录同名文件对应不同版本，不能混用旧版报告。

## 算法与 FPGA 实现

生产修改仅位于 `top_tf_hdmi_audio.v`：为现有增强模块增加 `PHOTO_SMOOTH` 编译参数，正式实例开启此参数。参数默认值 0 保留旧策略，便于独立模块复用和软件/RTL 对照。

使用现有因果 3×3 亮度邻域：当前像素及左侧两列、前两行，共两行亮度缓存。亮度为 `Y=(R+2G+B)>>2`。邻居与当前亮度差超过 24 时，用当前亮度替代该邻居，减少跨越明显边缘的混合。图像边界和未初始化 RAM 通过现有行列有效掩码排除。

中心权重为 8，另外八个邻居各为 1，计算整数均值 `N=(8Y+sum(neighbors))>>4`。默认照片档把亮度向 N 移动一半，采用对称舍入；相同修正加入三个颜色通道，并做饱和裁剪。它主要处理亮度纹理，不对色度通道单独滤波，也不是针对某种压缩格式的专用解码去块器。

复用原有缓存、加法流水线和自适应提亮。视频流在流水线充满后每个时钟接受一个有效像素，保持原有七拍增强延迟；坐标、DE、VS 与 RGB 同步。算法在字幕、赛事文字和 FFT 叠加之前执行，因此这些叠加内容不参与照片平滑。

这展示了 FPGA 对真实图像流的并行、持续处理能力；SD 卡读取、帧缓存和视频输出链路沿用稳定 2.0。本轮没有将素材预先修改后冒充实时处理，也没有新增帧缓存槽。

## 验证结果

| 项目 | 上一资源优化版 | 照片候选 |
| --- | ---: | ---: |
| LUT | 14565 | 14531 / 19600（74.14%） |
| 寄存器 | 9749 | 9723 |
| RAM9K | 55 | 55 / 64 |
| RAM32K | 11 | 11 / 16 |
| DSP | 11 | 11 / 29 |
| 建立 WNS | +0.110 ns | +0.131 ns |
| 保持 WNS | +0.022 ns | +0.032 ns |

TD 综合、布局布线及 bitgen 完成，STNS/HTNS 均为 0；原时钟和约束不变。上述面积变化是整机映射结果，不代表只靠此滤波改动在所有布局下都能节省相同数量的 LUT。

原 49 项回归与 3 项新增照片数值/旁路/流水线检查组成 52 项完整回归，通过；另单独运行合成块状纹理检查，共 53 项不同检查通过。新增质量检查在固定输入下测得弱纹理横向亮度总变差为 1632，旧锐化为 1792，同时保持强边缘、不产生过冲。这是指定合成纹理的结果，不是所有照片的画质提升百分比。

湖边照片完整 921600 像素经实际 RTL 仿真，旁路逐像素与输入一致；新旧算法在相同输入、固定 gain=1 下生成同区域对比。完整帧仿真验证了像素数和旁路对齐，不代表 FPGA 实板、HDMI 接收器或显示器已经验收。

报告位于 `releases/photo/reports`，包含资源、最终时序、回归日志、图像仿真日志、源码与位流哈希清单和 `comparison.png`。实际照片参考中改善较温和，不能保证明显消除源图的所有块状纹理。

## 实板待验收

依次检查五张照片的原图旁路、照片档及左右对比；尤其观察草地、树叶和电车轮廓是否更自然，是否出现过度发软、偏色或边缘拖影。再检查动画、切图、五首音乐、音量、FFT/波形、设置页及比赛页。出现明显变软时可关闭增强或回退上一资源优化位流。

插值和局部滤波不能恢复源图中已经丢失的真实细节。该候选目标是改善视觉块状感，并提供可运行、可测量的 FPGA 图像处理演示；真实清晰度提升程度以同屏对比和实板观察为准。
