## 2. 断电后接线

这里的 D14、G11 是 FPGA 芯片管脚名。实际插杜邦线时使用开发板 **J1 扩展口**：

| 串口屏端 | FPGA 开发板端 | 信号方向 |
|---|---|---|
| TX | J1 第 1 脚，GPIOA_0，对应 D14 | 屏幕→FPGA |
| RX | J1 第 2 脚，GPIOA_1，对应 G11 | FPGA→屏幕 |
| GND | J1 第 12 脚 GND，或第 30 脚 GND | 共地 |
| VCC | 按屏幕电源端标注供电 | 电源单独确认 |

开发板手册第 13 页的 J1 分配表与当前 `pin.adc` 一致。按接口的 1 脚标记和实物缺口方向认脚；不要只凭“左上角”判断。J1 第 11 脚为 5 V，第 29 脚为 3.3 V，第 12/30 脚为地。

用户确认新屏 TX/RX 为 **3.3 V TTL**，因此上述两根信号线可直连当前 LVCMOS33 引脚。**3.3 V 信号不代表屏幕 VCC 也应接 3.3 V**：若电源端标 5 V，就使用稳定的 5 V 电源；本次未核实该屏供电电流，不把开发板 J1 的 5 V 引脚作为默认供电方案。

将 USB 转 TTL 的 **TX、RX 两根信号线从屏幕拔下**，再接 FPGA，避免两个发送端同时驱动屏 RX。若继续由 USB 转 TTL 给屏供电，保留所需电源线并与 FPGA 共地；如果改用独立电源，就不要再并接 USB 转 TTL 的 VCC。也不要同时并接两个电源的正极。

其他连接：

1. FPGA 开发板按原来已验证的方式供电，下载器接板上 JTAG 下载口。
2. 显示器接 **HDMI_A**，选择对应 HDMI 输入；本工程不是 HDMI_B。
3. 原来已经工作的 TF 卡插在开发板 TF 槽，插拔时断电。
4. 音频通过 HDMI 输出；显示器需有扬声器或音频输出，并取消静音。
5. UART 为 **115200、8 数据位、无校验、1 停止位、无流控**。

## 4. 按顺序验证

### A. 启动和 FPGA→屏幕

1. 先给屏幕供电，再启动 FPGA，等待 TF 卡扫描完成。
2. HDMI_A 应有正常图片播放，首页“图片读取”“音乐读取”应变成 FPGA 扫描所得数量，正常完成后报错字段应显示 `OK`。
3. 使用本工程配套完整 TF 素材时，普通轮播图片最多 5 张，音乐最多 5 首；专用百米赛果背景不计入普通轮播图片数。其他卡按实际有效素材数核对。
4. LED0 对应轮播态，LED1 对应 TF 初始化完成，LED2 对应 HDMI_A HPD；LED3 对应错误或 FIFO 异常。

**屏幕亮、初始数字显示 0 不证明通信正常。** 必须看到屏幕状态随 FPGA 扫描结果变化。如果 FPGA 图片播放正常而屏幕始终停在初始值，先查 FPGA G11→屏 RX。

### B. 屏幕→FPGA 与播放控制

在轮播状态下点“上一张图片”“下一张图片”，HDMI 图片应随操作改变；点“切换歌曲”，音乐应切到下一首，多次操作应循环。切歌只在允许的轮播状态下生效。卡只有一首有效音乐时无法验证切歌。

若首页数量和状态可更新，但屏幕按钮无效，先查屏 TX→FPGA D14。

### C. 参数双向同步

1. 屏幕进入设置页，改变亮度、对比度、饱和度、锐化、音量和反色/复古开关，核对 HDMI 画面及音频发生对应变化。
2. 离开设置页再回来，参数应回显 FPGA 当前值，不能因为进入页面被清零。FPGA 对连续参数有量化，回写值可能与拖动值略有差别。
3. 在 FPGA 轮播态按 KEY3 进入板端设置，再用 KEY1 切换参数、KEY2 减小、KEY4 短按增大；核对串口屏相应数值也更新。完成后按 KEY3 退出板端设置。
4. 点屏幕恢复默认，核对画面恢复及参数回显，不只检查滑块本地位置。

### D. 赛事计时同步

1. 在屏幕首页点“开始比赛”，HDMI 应进入准备、3/2/1 倒计时和比赛状态。
2. 比赛开始后，屏幕 `MM:SS` 与 HDMI 显示应同步，无持续累积偏差。
3. 点“暂停比赛”，等待 5 秒，两边计时都应冻结；重复点暂停不能恢复。
4. 点“继续比赛”，两边继续计时；重复点继续不能暂停。
5. 点“结束比赛”，HDMI 应显示结束并返回轮播流程。

屏幕旧本地计时器已关闭；暂时断开 FPGA→屏幕信号后，屏幕时间不应自行继续走。该断线检查为可选，操作前断电。

### E. 本次新增 KEY2 流程

在**轮播态、未进入板端设置、未播放赛果动画**时测试：

1. KEY2 短按并松开：出现蓝方获胜动画。
2. 等动画停稳，再短按 KEY2：直接进入排名展示，不插入红方获胜画面。
3. 退出赛果回到轮播后，KEY2 按住满 1 秒：出现红方获胜动画；松开不能再次触发蓝方。
4. 等红方动画停稳，再按 KEY2：进入排名展示。
5. 比赛进行中 KEY2 仍为暂停/继续；板端设置中仍为减小参数。
6. 屏幕的蓝方、红方、百米展示和退出按钮仍应有效；退出按钮应返回轮播。

排名画面为已有演示，不是实时采集成绩或真实排名系统；本次未新增真实排名功能。

### F. 稳定运行

完成上述功能后连续运行 10 分钟，其间多次切图、切歌、改参数和暂停/继续，观察是否有黑屏、花屏、音频异常、屏幕重启或计时失步。记录所用位流哈希、TF 卡、操作及异常现象。这是建议的现场复验，不表示本次已代为完成。

## 5. 快速定位

| 现象 | 优先检查 |
|---|---|
| HDMI 正常，屏幕状态不更新 | G11→屏 RX、共地、115200、是否仍接原 X570 屏 |
| 屏幕状态更新，按钮不起作用 | 屏 TX→D14，当前操作是否被状态限制 |
| 两个方向都不通 | TX/RX 交叉、J1 实际脚位、共地、TTL 模式、是否已拔 USB 转 TTL 信号线 |
| 屏幕闪烁或反复重启 | 屏幕电源电压及供电能力 |
| HDMI 黑屏 | HDMI_A、显示器输入、位流、TF 卡及 E05/HPD 状态 |
| E01/E02 | TF 插入、初始化和原来已验证的卡 |
| E03/E04 | 有效 BMP、素材连续存储、读卡与整帧写入 |
| KEY2 仍先蓝再红，或短按推进会重启蓝方 | 是否烧入本页指定的最新位流 |
