# 本次屏幕修改：音乐计数、切歌、退出动画

适用串口屏 TJC8048X570；串口 115200、8N1。

## home.t_m

保留文本控件名称 t_m，vscope=全局。FPGA 自动写入已识别的有效 AUD 音乐数量（0–5）；不需要新增查询事件。计数来自 TF 扫描器，扫描完成后为最终数量，不统计普通 MP3/WAV 或格式不受支持的文件。

## home.b_music

清空按钮原触摸弹起事件中的开始比赛指令（01）和 page game，替换为：

```text
printh 55 08 00 00 ff ff ff
```

按下事件不再重复发送；取消“发送键值”。每点一次切换下一首，末首循环回第一首。按钮不离开 home，也不改变 t_m 的总数量。仅图片轮播、非赛果播放、非板载设置模式且至少两首有效音乐时执行；比赛中不切歌。

## 退出 FPGA 赛果动画

结算页新增按钮（如 b_exit），或修改现有返回首页按钮，触摸弹起事件：

```text
printh 55 23 00 00 ff ff ff
page home
```

23 指令在下一个视频帧边界退出蓝方/红方获胜、排名及领奖台显示，清除待执行的动画。重复退出不会重新启动。只执行 page home 无法停止 FPGA 输出的动画。

## 验证

保存、编译 HMI，下载生成的 TFT；FPGA 需要烧录本次新的合格位流。TF 扫描完成后验证 t_m 为有效曲数，连点 b_music 验证顺序及末首回环，再启动各赛果动画并点击退出。完整其他页面配置仍按 HMI_编辑器操作清单.md。
