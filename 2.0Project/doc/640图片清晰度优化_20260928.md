# 640×480 图片专用清晰放大

在此前保细节版基础上，仅对 640×480 → 1280×720 改用最近邻像素选择，关闭横向及纵向的颜色混合。小字体、细线不再被两次插值扩散；斜线及曲线可能有更明显的阶梯。不是超分辨率，不能恢复源图缺失的细节。

算法沿用原 Q16 端点对齐坐标。分数低于 0.5 选前一个样本，否则选后一个；整数位置直接选当前样本。最近邻改动未改变图像方向、输出像素数、写入节拍或行缓存银行数量；配套时序修复另将图像调节的流水线从五级延长到八级，详见后文。横向仍是约两倍放大，但由于端点对齐/定点量化，并不宣称每个像素都严格复制两次。

640×480 的 4:3 图像仍铺满 16:9 输出，本次没有改变原有拉伸方式。1280×720 图片仍原生直通，其他尺寸仍双线性；音频、HMI、动画、SDRAM 刷新逻辑未改变。
