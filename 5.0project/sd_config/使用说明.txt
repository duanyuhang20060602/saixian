# 从 SD 卡设置题目

本次版本的标题和底部滚动文字分别设置，各最多 16 个字符。默认工具使用微软雅黑生成中文、英文、数字和标点点阵。4 个字以内的标题保持静止，较长标题和底部文字共用滚动相位，内容与长度独立。只改变显示文字，不改变比赛项目、计时或比赛规则。

首次使用需要更新 A、B 两块板的配套固件。以后改题目只更新 SD 配置并重启两块板，无需重新编译或烧录固件。

## 修改方法

1. 在电脑上运行 `tools/configure_sd_title.cmd`，分别输入标题和底部文字，保存为 SD 卡上的 `TITLE2.BIN`。工具需要 Python 3 和 Pillow（`python -m pip install Pillow`）。
2. 下次修改时，用工具选择 SD 卡上**同一个已有的 `TITLE2.BIN`**。工具按原位置写入固定 2048 字节，不删除、截断或重建已有配置文件。不要在卡上保留多个新版配置副本。旧 `TITLE.BIN` 可以保留，新固件会忽略它；不要用新格式覆盖旧的 1024 字节文件。
3. 完成写入后安全弹出 SD 卡，插回 B 板，重启两块板。通过 SD 校验、完整传输后才启用新文字；缺少或损坏配置时保留原版文字。

也可以使用命令行分别输入：

```powershell
python tools/configure_sd_title.py --title "100米" --ticker "欢迎参加运动会" --output E:/TITLE2.BIN
```

将示例中的 `E:` 改成实际 SD 卡盘符。板子读取的是生成的 `TITLE2.BIN`，不是 TXT。旧 `--text/--text-file` 参数仅用于旧版工具兼容测试，会生成旧格式，不应用于本版独立文字。

## SD 素材位置要求

本功能沿用项目已有的扇区素材扫描，**没有增加 FAT 文件名解析器**。配置必须位于与现有素材相同的扫描范围：SD 卡前 512 MiB。首次整理素材时应先放置唯一的 `TITLE2.BIN`，再放照片、音乐等素材；后续通过工具原位修改它。现有照片、音乐的存放要求不变。不能保证把配置随意复制到一张已装满大文件的卡上就能被找到。无需重新制作照片/音乐/奖杯素材，无需格式化 SD 卡。

四个配置记录各自按 512 字节对齐，带版本、相同配置标识及 CRC32；无需占用一张照片位置，也无需增加额外的照片传输。B 板读取时复用已有 SD 扫描和原来的一块 RAM9K，通过现有 UART 可靠传输；A 板复用原有 32K 字库 RAM 中的 96～127 号字模槽，不另开中文字符表 RAM。

资源与时序以最终构建报告为准。实板显示、SD 卡兼容性及上电行为仍需硬件验收。
