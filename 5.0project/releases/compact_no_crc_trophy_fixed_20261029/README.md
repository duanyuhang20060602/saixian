# 原速率、去占位、去调试配套固件

基于 20412cd84c6d6772850d7431f6b63872fcc3687d，接续先前去 CRC/保护精简版本。原有交付未覆盖，未删除文件。

频率保持：控制 UART 230400；外接 HMI UART 115200；SPI HALF_DIV=10，即 75 MHz/(2×10)=3.75 MHz；图片并行链路 25 MHz。空轮询间隔恢复原来的 1 ms。中间提频实验已停止，不在本交付内。

控制 UART 从 24 字节缩为 20 字节（A5 5A + 18 字节数据），去掉原 CRC 的两个零占位字节及消息末尾两个固定零保留字节；接收后在内部恢复保留位为零。使用两拍内部发布流水，保持控制器预解码在 received 脉冲前稳定，不占用串行字节。

SPI 响应去掉 CRC 占位字，并同步调整计数、数据范围、PCM 起始位置及最后一个数据字的提交时机。HMI-only 从 7 个字缩为 6；HMI+128 PCM 从 135 缩为 134；AV 从 293 缩为 292；relief 从 388 缩为 387。必要包头、长度、实际数据、ACK 去重及流控保留。全双工传输期间的反向空闲位不额外占用周期。

调试逻辑移除：切图时间探针与计时显示，数码管状态/诊断显示，A 板扫描/时钟监测、启动首错和显示用跨时钟寄存器，B 板首错与奖杯错误锁存。数码管关闭。仅用于这些输出的内部诊断寄存器由综合裁剪；源文件仍保留。B 板 transfer_done/transfer_error 状态接口保留。

验证：230400 双向异步时钟 UART 各 16 包数据一致；16 组消息测试从 16.70 ms 减为 13.92 ms（约减少 16.7%，来自包长缩短）。SPI：3072 PCM 字与 85 HMI 字节逐项一致，AV/relief/page/HMI-only 覆盖，音频无欠载。真实控制 UART 标题协议：128 字与 256 行字模一致、丢 ACK 重传、去重、帧消隐发布通过。顶层音画同步检查通过。两板源文件与工具哈希不变，布局布线及时序通过。

两块板必须同时使用本目录的配套 bit；20 字节控制协议不兼容旧的 24 字节固件。SD 素材格式不变。实板尚未验证，未声称实测 SD 卡读取或整帧加载速度提升。

奖杯修复：去掉 SPI CRC 占位字后，最后一个数据字和提交信号同拍。奖杯接收器增加一拍内部提交延迟，确保最后一字的计数和写入完成后再发布；不恢复线上占位、不提频。旧版旋转奖杯回归已复现，修复后连续三个角度表正常发布。

真实 SPI 联合检查通过：奖杯表 active_valid 和显示角度正确，5078 PCM 字、116 HMI 字节一致，4 次 relief 传输，音频无欠载。
