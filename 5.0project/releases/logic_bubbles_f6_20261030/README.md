# f6 逻辑与空拍优化版本

基线：f6f73053b29eed2b5ac463002dd87c311c142f8a。
请分别将 PHOTO_BOARD_A.bit、PHOTO_BOARD_B.bit 下载到 A、B 板。

## 修改

- HMI BYTE_STREAM 在握手成功后直接发送下一字节，使用同步前缀 ROM 预取，保留命令开始的必要准备周期。
- 有限档位先选择输入，再共用一套百分比字符编码，替代通用十进制除法与取模。
- 时钟、串口波特率和双板协议维持基线；保留奖杯旋转所需的提交时序。没有加入音乐快进。

## 布局布线后的实际资源

| 板卡 | LUT 前 → 后 | 寄存器 前 → 后 | RAM9K / RAM32K | DSP | Setup / Hold 裕量 ns |

| A | 17253 → 17253 | 12305 → 12305 | 62 / 15 | 27 | 0.153 / 0.020 |
| B | 15549 → 15529 | 10875 → 10878 | 58 / 16 | 16 | 0.100 / 0.033 |

## 验证

32 组与 f6 原模块的逐字节对比均通过，覆盖 0～15 档位/状态、随机背压、32 字节命令和刷新计数回绕。
设置页输出 407 字节：无背压 830 → 437 拍（减少 47.35%）；本测试随机背压 2095 → 1713 拍（减少 18.23%）。
这是内部组包耗时，不代表屏幕刷新或整体系统速度提升同样比例。HMI 串口仍为 115200。
真实 A/B SPI 模块联合仿真：5078 PCM 字精确一致、116 HMI 字节精确一致、奖杯数据提交通过、音频下溢为 0。
双板均在原约束下通过最终布线后 setup/hold 检查；尚未进行实体板下载验证。
