# SD 卡题目与首页优化候选

通过电脑工具原位更新 SD 卡上的同一个 `TITLE.BIN`，重启后，首页标题和从左向右滚动的文字同步改变，最多支持 16 个字符。首次使用需要更新本目录配套的 A、B 两板固件；之后改题目无需重新编译或烧录。

解压完整包，运行 `title_tool/configure_sd_title.cmd`。工具需要 Python 3、Pillow 和中文字体，默认使用 Windows 微软雅黑。

## SD 卡使用条件

配置文件必须位于 SD 卡前 **512 MiB**。此功能复用原版素材扇区扫描，没有新增 FAT 文件名解析器；首次整理素材时应先放置唯一的 `TITLE.BIN`。以后用工具直接更新卡上同一个文件，不要删除重建或另存多个副本。完成写入后安全弹出 SD 卡，再插回 B 板并重启两块板。

板子读取生成的二进制配置；`TITLE.txt` 是电脑工具的输入文件。4 字以内的标题保持静止，较长标题与底部文字共用滚动位置。配置缺失、损坏或未完整传输时保留原版文字。改题目不改变比赛项目、计时或规则。
