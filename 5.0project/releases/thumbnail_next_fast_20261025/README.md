# 缩略图提速与下一张按钮固件（2026-10-25）

基于 main 的 390690f，包含双板传输/素材加载提速，以及缩略图加速和交互调整。尚待实板验证。

- 缩略图移至右侧原下一张箭头区域，160×90，左上角 (1096,315)。
- 去掉原箭头，点击缩略图、标题或边框即可切换下一张；隐藏时不响应。
- 保持 112×63 RGB565 缓存画质，采用 64 字对齐批量采样。
- 在下一张完整缓存已就绪的相同 720p 仿真中，预览发布由第 7 帧提前至第 3 帧，约提前 66 ms，不包含 SD 读取或板间传输等待。
- 12 项有效仿真验证通过；A 板建立/保持时序余量分别为 0.159 ns / 0.027 ns，TNS 为零。
- B 板复用上一份通过的传输提速固件，源输入哈希一致。已经使用该 B 固件时只需更新 A。
