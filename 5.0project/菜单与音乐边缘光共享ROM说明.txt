5.0 菜单与音乐边缘光共享 ROM / shared-menu-edge-rom-20261025

菜单文字字形编号表原为 1024x8，最后 128 字节逐项验证全零。把原音乐边缘光 128x8 权重无损放入这些地址，两者分别使用同一块 RAM9K 的 A/B 两个同步只读端口。菜单读取最后 128 字节时仍输出零，边缘光读取原始权重；并行吞吐、单拍 ROM 延迟、菜单 4/6/21 拍与边缘光五拍输出对齐保持。
这次仅改 A，B 编译输入与现有合格固件逐项哈希相同，因此复用 B，不声称重新编译。奖杯/彩带 DSP 共享、精确插值、彩色水波、音乐和 TF 标题保持。音频缓冲、分辨率、素材和时序约束未改变，现有 TF 卡可继续使用。

实际完整布局布线
A LUT 18271 -> 18588；REG 12816 -> 12809；RAM9K 63 -> 62 /64；RAM32K 16/16；DSP 28/29；MSlice 4764 -> 4819 /4900。
B LUT 16357，REG 11050，RAM9K 57/64，RAM32K 16/16，DSP 16/29，MSlice 4506/4900，均未变。
A 建立/保持余量 +0.119/+0.024 ns；B +0.054/+0.022 ns；建立和保持总违例均为零。物理布局会改变其他资源指标，不把节省 RAM 等同于所有 LUT/切片指标都下降。
本轮明确用额外 317 个 LUT、55 个 MSlice 换出一块 RAM9K，适用于优先腾出 RAM 的阶段。另一个仅改边缘光的普通 LUT 常量表候选需要较少 LUT，但两次布局仍有建立时间违例 -0.612/-0.437 ns，没有发布其 bit 或把其结果混作本版通过。

验证：120 条当前有效记录，其中新跑 17，其余 103 条逐项核对输入哈希后沿用。双端口 131072 种地址组合全部穷举；行为/厂商 RAM 模型下完整 720p 菜单和边缘光逐时钟对照；PCM/外部包络、亮度、场景开关和复位；默认配置全 2097152 坐标与菜单 4/6/21 拍兼容性；顶层显示、结果按键和缩略图触控。
原始菜单表和边缘权重 MIF 保留。若以后改菜单或权重，请运行 python -B tools/prepare_menu_edge_rom.py；构建入口会检查打包是否过期，也会检查菜单被占用区是否仍全零，避免新字形覆盖权重。

固件：releases/PHOTO_BOARD_A_5_0.bit。B 若已有 shared-award-math-20261025 配套合格固件，可保留，否则使用本目录 PHOTO_BOARD_B_5_0.bit。此次仿真、布局布线与保存完整性通过，实板验收仍待重新烧录确认。失败/调试运行不计入通过记录。
